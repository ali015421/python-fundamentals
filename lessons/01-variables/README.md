
## 01-variables/README.md

### What this covers
Variables, assignment, reassignment, naming conventions, print().

### The problem
Needed a way to store and reuse values (salary, revenue, expenses) instead of
retyping numbers everywhere.

### Approach
Used variables as named references to values, then basic arithmetic
expressions on them (profit = revenue - expenses style).

### Key concepts practiced
- Variables as names bound to values in memory, not the values themselves
- Reassignment changes what the name points to, not the old value
- Python is dynamically typed — no manual type declarations

### Bugs I hit
- None major at this stage — mostly conceptual.

### How to run
```
python3 lesson.py
```
